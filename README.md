# Good Pass

Небольшой образовательный веб-сервис на чистом HTML, CSS и JS. Он объясняет стойкость
пароля, оценивает примерное время перебора и даёт подсказки, что уже хорошо и что можно
улучшить. Интерфейс компактен и адаптивен, а дополнительно вшиты генератор стойких паролей,
пасфраз Diceware и проверка утечек через k-anonymity.

## Возможности

- мгновенная оценка стойкости, времени перебора и энтропии;
- переключатели модели атакующего (онлайн/оффлайн) и вариантов хэширования с формулой расчёта;
- советы по сильным сторонам, анализ шаблонов (словари, раскладки, последовательности);
- детекторы персональных данных, гомоглифов, дорожек по клавиатуре и смешанной раскладки;
- проверка пароля в публичных утечках через Have I Been Pwned c k-anonymity и подсказками по приватности;
- генератор паролей с настройкой длины/наборов символов и отдельный генератор пасфраз Diceware;
- блок «Временная почта»: одно нажатие — и есть временный адрес, таймер на 10 минут, список писем и просмотр содержимого;
- локализация (RU/EN/UZ-заглушка) и переключатель тем (светлая/тёмная/авто/высокий контраст) для доступности.

## Быстрый старт

```bash
npm start
```

Команда запустит лёгкий статический сервер на `http://localhost:3000` и будет отдавать файлы
из каталога `public/`. Скрипт удобен для локальной проверки интерфейса.

## Тесты

```bash
npm test
```

Тесты используют встроенный `node:test` и покрывают расчёт энтропии, оценку времени перебора и
форматирование длительности.

## Деплой на Cloudflare Pages

Сервис отдаётся как статический сайт с функциями Pages Functions для временной почты.

1. Подключите репозиторий в Cloudflare Pages и выберите пресет **"None"**.
2. В качестве build command оставьте поле пустым либо укажите `npm run build` (опционально —
   скрипт просто копирует `public/` в `dist/`).
3. В поле **Build output directory** укажите `public` (или `dist`, если используете шаг выше).
4. Задайте переменную `NODE_VERSION=18` для совместимости с локальными скриптами предпросмотра.
5. Для блока «Временная почта» добавьте переменные окружения и при необходимости KV:
   - `TEMP_MAIL_API_BASE_URL` — базовый URL внешнего temp-mail провайдера.
   - `TEMP_MAIL_API_KEY` — ключ авторизации, если нужен.
   - `TEMP_MAIL_MODE=mock` — опционально включает мок-провайдер для локальной разработки без внешнего API.
   - `TEMP_MAILBOX_KV` — KV-binding для хранения активных ящиков и TTL (опционально, есть in-memory запасной вариант).

После публикации сайт будет отдавать содержимое каталога, поэтому все пути в `index.html`
относительные и работают из любых поддиректорий.

### API для временной почты

Pages Functions предоставляет компактный прокси к любому temp-mail сервису:

- `POST /api/temp-mailbox` — создаёт ящик, возвращает `mailboxId`, `address`, `expiresAt`, `accessToken`.
- `GET /api/temp-mailbox/:id/messages` — список писем при валидном `accessToken` в query/заголовке.
- `GET /api/temp-mailbox/:id/messages/:messageId` — детали письма, HTML проходит базовую очистку.

TTL 10 минут проверяется на бэкенде при каждом запросе, фронтенд показывает обратный отсчёт и останавливает опрос по истечении.
