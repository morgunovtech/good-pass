# Good Pass

Небольшой образовательный сервис, который объясняет стойкость пароля, оценивает
время перебора и подсказывает, как сделать пароль сильнее.

## Запуск

Зависимостей нет, поэтому установка не требуется. Для локального предпросмотра:

```bash
npm start
```

Сервис поднимется на `http://localhost:3000` и будет раздавать статический контент из
каталога `public/`. Скрипт удобен для локальной проверки, но для деплоя на Cloudflare
Pages достаточно указать `public/` как директорию билда (Node-сервер не нужен).

## Проверка

```bash
npm test
```

Тесты используют встроенный `node:test` и покрывают основные сценарии анализа стойкости.
